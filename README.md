# マイメニュー（プロトタイプ）

自分ひとり用のルーティーン管理。種目を登録 → メニューに組む → 今日の分を1つずつ潰す → つみかさねが見える。

## 使い方

**https://masanobu6.github.io/my-routine/**

データはその端末のブラウザの中（localStorage）に入る。サーバーには何も送らない。

### スマホに入れる（Android Chrome）

1. 上のURLを Chrome で開く
2. 右上の ⋮ →「アプリをインストール」（または「ホーム画面に追加」）
3. ホーム画面のアイコンから開くと、アドレスバーの無い全画面になる

インストールには HTTPS が要る。`http://192.168.x.x` のようなLANのアドレスでは、
Chrome はインストールを提案しないし Service Worker も動かない。

### 手元で直す

`index.html` をブラウザで直接開けば、そのまま動く（Service Worker だけは動かない）。
ローカルでサーバーを立てるなら:

```bash
python -m http.server 8790 --bind 127.0.0.1 --directory C:/ClaudeCode/my-routine
```

### 公開しなおす

`git push` するだけ。GitHub Pages が1〜2分でビルドして差し替わる。
スマホ側は再読み込みすれば最新になる（Service Worker はネットワーク優先にしてある）。
どの版を見ているかは「ごほうび」画面のいちばん下に出る（v0.9 など）。

## 画面

| 画面 | できること |
|---|---|
| 今日 | 今日のメニューとスポット作業。はじめる／ミニ版／休む。連続日数、のこり時間 |
| 実行モード | 1種目ずつ全画面。セットと休憩タイマー、経過時間 |
| メニュー | メニューの作成・曜日と時刻・種目の並べ替え |
| 種目 | 部品の登録。単位（回・分・秒・ページ・個・km・チェック）とかかる時間 |
| ごほうび | ポイントの残高とレベル。ごほうびの登録と交換、交換履歴 |
| 記録 | 草カレンダー、連続日数、ポイント、30日の合計、最近の記録 |

## ポイント

**5分で1pt**。それだけ。5分に足りないぶんは切り捨てる。点を自分で決める欄は無い。

| | 時間の出どころ |
|---|---|
| メニュー | 種目に決めた「かかる時間」の合計 |
| スポット作業 | タイマーではかった実際の時間 |

おまけ:

- メニューやスポット作業を**やりきる**と ＋1pt
- その日の**1本目**に ＋1pt（続くほど増えて、最大5pt）

貯まったポイントは「ごほうび」で交換する。100ptごとにレベルが1つ上がる（100pt ＝ 約8時間）。
記録を取り消すとそのぶんのポイントも消える。交換ずみで足りなくなる場合は、先に交換履歴を消す。

### スポット作業の進め方

1. 「はじめる」を押すとタイマーが動く（画面に経過時間が出る）
2. 終わったら「**おわり**」… 実際にかかった時間で記録し、タスクは完了
3. 途中でやめるなら「**途中まで**」… 時間は記録され、**タスクは残る**。次は「つづき」から
4. 記録したくないときは「やめる」

「途中まで」を何度くり返しても、時間は足し算される。5分に足りない端数も次に持ちこす
（12分＋8分＝20分 → 4pt）。タイマーを押し忘れたときは、編集画面の
「時間をはからずに終わりにする」で目安の時間を使って終われる。

## スポット作業

毎日やるものではない、1回かぎりの用事（確定申告の書類をそろえる、など）。
「今日」の画面から足す。やる日は決めなくてよく、決めなければ「いつかやる」に並ぶ。押した日で記録される。
日を決めておけば、その日になったら今日の画面に出てくる。過ぎても消えず「3日すぎ」と出る。

## カテゴリと時間

種目もスポット作業も、**IT／ファイナンス／英語／筋トレ／その他**のどれかに入れる。
色はカテゴリで決まる（種目ごとの色えらびはカテゴリに置きかえた）。
**かかる時間（分）**は目安。今日の画面に「のこり 2メニュー＋スポット1件 ・ 1時間40分」と出るので、
寝る前に「40分なら今からやれる」と判断できる。
記録の画面には、この30日をカテゴリ別に集計した棒（回数・時間・ポイント）が出る。

## 考え方

- **種目とメニューは別物**。「スクワット」は朝メニューにも筋トレの日にも入れられて、記録は種目単位でまとまる。
- **ミニ版**は量を3割にしてセットを1回に落とす。時間も3割で数えるのでポイントは減るが、ゼロにはならない。ゼロの日を作らないため。
- **ストリークは折れにくく**してある。「休む」を押した日と、そもそも予定のない日はカウントを切らない。何もしないで放置した日だけ切れる。

## 記録をサイトに出す

「記録」タブの下に、もそもそ奮闘記に載せるための書き出しがある。
出るのは**数字だけ**（日ごとの達成レベル・分数・ポイント、カテゴリ別の合計）で、
種目名やスポット作業の中身は入らない。

- **書き出してコピー** … クリップボードに入れる。貼りつけて使う
- **ファイルで保存** … `records.json` として保存する
- **自動で送る** … あずかり所（`worker/`）を立てると、やり終えるたびに自動で送られる

送信先のURLとあいことばは、そのスマホの中だけに保存される。書き出すデータには入らない。

ブログ側のページは `mosomoso-history/src/pages/routine.astro`。
`data/records.json`（または Worker）をブラウザから読むので、ブログを作り直さなくても数字が新しくなる。

## まだ入っていないもの

- 通知（Web Push）。送信側の仕組み（Cloudflare Workers の cron など）が別に要る
- 種目ごとの伸びグラフ、週次のふりかえり
- 端末をまたぐ同期（いまは端末ごとに別のデータ）
