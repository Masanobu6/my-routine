# マイメニュー（プロトタイプ）

自分ひとり用のルーティーン管理。種目を登録 → メニューに組む → 今日の分を1つずつ潰す → つみかさねが見える。

## 使い方

**https://masanobu6.github.io/my-routine/**

データはまずその端末のブラウザの中（localStorage）に入る。同期を入れると、
あずかり所（Cloudflare Worker）を通してスマホとパソコンで同じ中身になる（下の「端末どうしの同期」）。

### スマホに入れる（Android Chrome）

1. 上のURLを Chrome で開く
2. 右上の ⋮ →「アプリをインストール」（または「ホーム画面に追加」）
3. ホーム画面のアイコンから開くと、アドレスバーの無い全画面になる

インストールには HTTPS が要る。`http://192.168.x.x` のようなLANのアドレスでは、
Chrome はインストールを提案しないし Service Worker も動かない。

### 手元で直す

`index.html` をブラウザで直接開けば、そのまま動く（Service Worker だけは動かない）。
ローカルでサーバーを立てるなら:

```bash
python -m http.server 8790 --bind 127.0.0.1 --directory C:/ClaudeCode/my-routine
```

### 公開しなおす

`git push` するだけ。GitHub Pages が1〜2分でビルドして差し替わる。
スマホ側は再読み込みすれば最新になる（Service Worker はネットワーク優先にしてある）。
どの版を見ているかは「ごほうび」画面のいちばん下に出る（v0.9 など）。

## 画面

| 画面 | できること |
|---|---|
| 今日 | 今日のメニューとスポット作業。はじめる／休む。連続日数、のこり時間 |
| 実行モード | 1種目ずつ全画面。セットと休憩タイマー、経過時間 |
| メニュー | メニューの作成・曜日と時刻・種目の並べ替え |
| 種目 | 部品の登録。単位（回・分・秒・ページ・個・km・チェック）とかかる時間 |
| ごほうび | ポイントの残高とレベル。ごほうびの登録と交換、交換履歴 |
| 記録 | 草カレンダー、連続日数、ポイント、30日の合計、最近の記録 |

## ポイント

**5分で1pt**。それだけ。5分に足りないぶんは切り捨てる。点を自分で決める欄は無い。

| | 時間の出どころ |
|---|---|
| メニュー | 種目に決めた「かかる時間」の合計 |
| スポット作業 | タイマーではかった実際の時間 |

おまけ:

- メニューやスポット作業を**やりきる**と ＋1pt
- その日の**1本目**に ＋1pt（続くほど増えて、最大5pt）

貯まったポイントは「ごほうび」で交換する。100ptごとにレベルが1つ上がる（100pt ＝ 約8時間）。
記録を取り消すとそのぶんのポイントも消える。交換ずみで足りなくなる場合は、先に交換履歴を消す。

### 途中でやめるとき

メニューもスポット作業も、**途中まで**で区切れる。

- メニュー … 実行中の「途中までにして戻る」。やった種目ぶんが記録され、
  今日の画面に「途中まで 1/3」と出る。「つづき」を押すと**残りの種目から**再開する
- スポット作業 … 「途中まで」。時間が記録され、タスクは残る

どちらも、あとで最後までやりきれば「やりきった＋1pt」が付く。
同じ時間ぶんのポイントを二重にもらうことはない。

### スポット作業の進め方

1. 「はじめる」を押すとタイマーが動く（画面に経過時間が出る）
2. 終わったら「**おわり**」… 実際にかかった時間で記録し、タスクは完了
3. 途中でやめるなら「**途中まで**」… 時間は記録され、**タスクは残る**。次は「つづき」から
4. 記録したくないときは「やめる」

「途中まで」を何度くり返しても、時間は足し算される。5分に足りない端数も次に持ちこす
（12分＋8分＝20分 → 4pt）。タイマーを押し忘れたときは、編集画面の
「時間をはからずに終わりにする」で目安の時間を使って終われる。

## スポット作業

毎日やるものではない、1回かぎりの用事（確定申告の書類をそろえる、など）。
「今日」の画面から足す。やる日は決めなくてよく、決めなければ「いつかやる」に並ぶ。押した日で記録される。
日を決めておけば、その日になったら今日の画面に出てくる。過ぎても消えず「3日すぎ」と出る。

## 表紙・種類・参考URL

スポット作業にも種目にも付けられる（編集画面のいちばん上から）。

- **表紙の画像** … 1枚。本の表紙や講座のサムネなど。パソコンは Ctrl+V で貼りつけもできる。
  画像が無いときは、カテゴリの色に種類のアイコンが出る
- **種類** … 本／講座／アプリ／オリジナル／その他。「＋ 追加」で増やせて、端末どうしで同期する。
  自分で足した種類は、選んだときに出る「選択肢から消す」で消せる
- **参考URL** … カードの 🔗 から開ける。タイマー画面からも開ける。のちにブログに載せるときに使う

画像は長い辺800pxの WebP に縮めてから保存する（1枚およそ数十KB）。
**同期データには入れず**、画像のIDだけを持たせる。中身は端末の IndexedDB と、
あずかり所の `/img/<id>`（読むのにも鍵が要る）に別に置く。記録本体を軽いままにするため。

## カテゴリと時間

種目もスポット作業も、**IT／ファイナンス／英語／筋トレ／その他**のどれかに入れる。
色はカテゴリで決まる（種目ごとの色えらびはカテゴリに置きかえた）。
**かかる時間（分）**は目安。今日の画面に「のこり 2メニュー＋スポット1件 ・ 1時間40分」と出るので、
寝る前に「40分なら今からやれる」と判断できる。
記録の画面には、この30日をカテゴリ別に集計した棒（回数・時間・ポイント）が出る。

## 考え方

- **種目とメニューは別物**。「スクワット」は朝メニューにも筋トレの日にも入れられて、記録は種目単位でまとまる。
- **途中でやめてもゼロにならない**。メニューもスポット作業も「途中まで」で区切れて、やった分の時間はそのままポイントになる。ゼロの日を作らないため。
- **ストリークは折れにくく**してある。「休む」を押した日と、そもそも予定のない日はカウントを切らない。何もしないで放置した日だけ切れる。

## 記録をサイトに出す

同期するたびに集計があずかり所へ送られ、ブログの **Daily Progress**
（https://mosomoso-history.com/routine/）に出る。
中身は日ごとの達成レベル・分数・ポイント、カテゴリ別の合計と、その内訳の**作業名・種目名**。
ごほうびの中身と同期の設定は入らない。

「記録」タブの下の書き出し（コピー／ファイルで保存）は、同じ集計を手で取り出すためのもの。

## 端末どうしの同期

「記録」タブの**同期**で「**Googleで入る**」を押し、許可してあるGoogleアカウントで入る。
入った端末どうしで、記録の中身がそろう（スマホとパソコンなど）。
カードの見出しに、入っているアカウントと端末名が出る。

- 入ると、その端末だけの合鍵（端末トークン）が発行される。Googleに入り直す必要はない
- 許可するメールは Worker の secret `ALLOW_EMAILS` で決める。ほかのアカウントは入れない
- 前の**あいことば**方式も残してある（Googleが使えないときの予備）
- **いま同期する** … 取り込んで1件ずつ混ぜ、変わっていれば送る
- アプリを開いたときも自動で取り込む。自動送信を入れておけば、変えるたびに送られる

**合鍵・あいことば・端末名は、その端末の中だけ**に残り、送るデータには入らない。

## 同期の作り（v2.0）

塊の上書きをやめ、**1件ずつ**突き合わせる。事故を構造的に起こせなくするため。

| 仕掛け | 中身 |
|---|---|
| **版つき書き込み** | 「自分が読んだ版」を添えて書く。サーバーの版が進んでいれば 409。呼び手が混ぜて出し直す |
| **1件ずつのマージ** | IDで突き合わせ、両方にあるものは新しい方、片方にしかないものは必ず残す |
| **墓標（tombstone）** | 消したIDを記録して送る。消したものが他の端末から復活しない |
| **版の履歴** | サーバーが直近20版を保存。`GET /history` で一覧、`?v=3` で中身 |
| **激減ガード** | レコード数が半分以下になる書き込みは、`force` が無ければ拒む |
| **まっさらな端末** | 一度も触っていない端末は、初期データを持ちこまずに受け取るだけ |
| **固定ID** | 初期データのIDは固定。別の端末で作られても二重にならない |

2026-09-20 に、PCの空データがスマホの記録を消す事故が起きた。
上の「版つき書き込み」と「激減ガード」は、それぞれ単独でこの事故を止める。

置き場所は Cloudflare Worker（`worker/`）。`/data` と `/history` は読むのにも合鍵かあいことばが要る。
ブログが読む集計（`/`）だけが公開。

ブログ側のページは `mosomoso-history/src/pages/routine.astro`。
`data/records.json`（または Worker）をブラウザから読むので、ブログを作り直さなくても数字が新しくなる。

## まだ入っていないもの

- 通知（Web Push）。送信側の仕組み（Cloudflare Workers の cron など）が別に要る
- 種目ごとの伸びグラフ、週次のふりかえり
