# マイメニュー（プロトタイプ）

自分ひとり用のルーティーン管理。種目を登録 → メニューに組む → 今日の分を1つずつ潰す → つみかさねが見える。

## 使い方

`index.html` をブラウザで開くだけ。サーバーもログインも要らない。
データはその端末のブラウザの中（localStorage）に入る。

スマホで試すときは、PCでこのフォルダを配ってスマホから開く:

```bash
python -m http.server 8790 --bind 0.0.0.0 --directory C:/ClaudeCode/my-routine
```

同じWi-Fiのスマホから `http://<PCのIPアドレス>:8790/` を開く。

## 画面

| 画面 | できること |
|---|---|
| 今日 | 今日のメニュー。はじめる／ミニ版／休む。連続日数 |
| 実行モード | 1種目ずつ全画面。セットと休憩タイマー、経過時間 |
| メニュー | メニューの作成・曜日と時刻・種目の並べ替え |
| 種目 | 部品の登録。単位（回・分・秒・ページ・個・km・チェック）ともらえるポイント |
| ごほうび | ポイントの残高とレベル。ごほうびの登録と交換、交換履歴 |
| 記録 | 草カレンダー、連続日数、ポイント、30日の合計、最近の記録 |

## ポイント

| もらえるとき | ポイント |
|---|---|
| 種目を1つ終える | その種目に決めたポイント（種目の画面で変えられる） |
| メニューをやりきる | ＋10pt |
| その日の1本目 | 連続日数×2pt（最大30pt） |
| ミニ版 | 上の半分（切り上げ） |

貯まったポイントは「ごほうび」で自分の決めたごほうびと交換する。100ptごとにレベルが1つ上がる。
記録を取り消すとそのぶんのポイントも消える。交換ずみで足りなくなる場合は、先に交換履歴を消す必要がある。

## 考え方

- **種目とメニューは別物**。「スクワット」は朝メニューにも筋トレの日にも入れられて、記録は種目単位でまとまる。
- **ミニ版**は量を3割にしてセットを1回に落とす。ポイントは半分だがゼロではない。ゼロの日を作らないため。
- **ストリークは折れにくく**してある。「休む」を押した日と、そもそも予定のない日はカウントを切らない。何もしないで放置した日だけ切れる。

## 第1弾に入っていないもの

- 通知（Web Push）。設計は通知を足せる形にしてあるが、送信側の仕組みが別に要る
- 種目ごとの伸びグラフ、週次のふりかえり、ごほうびポイント
- ホーム画面へのインストール（manifest と service worker）
- 端末をまたぐ同期
